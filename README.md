# Freedom Unbound Mods

Released mods for the updated **Freedom Unbound native launcher**, targeting
**Monster Hunter Freedom Unite USA (`ULUS10391`)**. Mod author: **DuduX42**.

Only the latest version of each mod is published here. Download individual ZIPs
from the links below or the [release page](https://github.com/Dudux42/FreedomUnboundmods/releases/tag/mods-2026-10-16).
Packages are GitHub Release assets; cloning this repository downloads the catalog
and guides, not the mod ZIPs. This repository does not include the game or launcher.

## Install

1. Use an updated Freedom Unbound native launcher with support for these mods.
2. Download the desired ZIP without extracting it.
3. Drop it onto the launcher's **Mods** page, install it, then enable it.
4. Review that mod's guide for controls, supported behavior and remaining test limits.

Gameplay ZIPs select providers compiled into the launcher; they cannot add those
providers to an older build or be installed as standalone PPSSPP cheats. FU
retextured is a texture pack. Enable only one texture pack at a time.

## What each mod does

<a id="damage-numbers"></a>

### Damage Numbers

Displays bold damage numbers above attack impacts with a thin white outline. Normal hits are light orange, positive criticals add a small `*`, and negative-affinity hits are red.

<a id="gathering-nodes"></a>

### Gathering Nodes

Shows a green question-mark icon above the hunter near an available gathering, mining or bug-catching node. It hides when the weapon is drawn or the node is depleted. Hold the mapped Circle action to keep gathering; mining and bugs still require the appropriate tools. Release to stop.

<a id="monster-hp"></a>

### Monster HP

Stacks named HP bars at the bottom-left for large monsters in the current area, without requiring a hit first. No local large monsters means no bars. Bars disappear when quest gameplay ends and rewards begin.

<a id="modern-camera"></a>

### Modern Right-Stick Camera

Adds continuous horizontal and vertical right-stick camera movement during quests, within the original camera limits. Village and Hall camera behavior stays native, and the D-pad keeps working. The nearest living large monster in the area is selected automatically: ZL/LT/L2 faces it once; ZR/RT/R2 cycles targets without moving the camera. The target icon appears in its Monster HP bar, or beside its name when that mod is absent. Ranged aiming and special camera modes retain their original controls.

<a id="shared-guild-progression"></a>

### Shared Gathering Hall Progression

Gives joined players their normal local completion credit for successful Gathering Hall urgents. Regular Hall quests already share completion. Every participant who wants urgent credit must enable this mod locally. Native rank prerequisites and unlock checks still apply; past clears are not copied. This mod affects earned quest progress saved by the game. Full multiplayer rank progression and save/reload still need a playtest.

<a id="key-quests"></a>

### Flag Key Quests

Adds a gold star next to key quest names in Village and Gathering Hall quest lists. Reads all 77 native key quests across 18 tiers; it does not change completion requirements or unlock quests.

<a id="fu-retextured"></a>

### FU retextured

Combined HD texture pack for environments, menus, fonts, title artwork, hunter and equipment textures. Version 0.8.1 improves cut-out edges, fixes several tiling seams and redraws the title logo. It includes the surveyed female armor additions; male variants, every dye and all animation states have not been audited. Enable one texture pack at a time.

<a id="return-timer"></a>

### Quest Return Timer

Displays the native 20- or 60-second return countdown at the top-center after quest success, with a red warning in the last ten seconds. It displays the game timer; it does not shorten the return period.

<a id="buff-icons"></a>

### Buff Icons

Places small buff icons in a compact row beside the sharpness gauge, without numeric timers. Icons pulse with 30 seconds left, pulse and flash red with ten seconds left, then disappear and close the gap on expiry. Supports timed item effects and local Hunting Horn effects; permanent drug effects, food/armor skills and negative statuses are outside this display.

<a id="equipment-wishlist"></a>

### Equipment Material Pin

At the smithy, ZR/RT/R2 pins the selected equipment recipe and ZL/LT/L2 removes it. Pins appear beside equipment and materials; the checklist tracks owned and missing materials internally. Small queued pickup/readiness notices last five seconds, with at most three visible. Ready-equipment notices repeat after loading or returning to the visible village. Pin/unpin confirmations appear top-left for three seconds. Successful crafting or upgrading automatically removes that recipe’s pin. Overlapping recipes check stock independently, without reserving items.

<a id="gathering-map-markers"></a>

### Gathering Map Markers

Adds gathering, mining and bug icons to the native quest map for the current area only. Depleted nodes are hidden, and markers follow map zoom. Works independently of Gathering Nodes.

<a id="controller-prompts"></a>

### Controller Prompts

Replaces recognized vanilla button sprites with their mapped keyboard/controller assignments, and supplies live Switch, PlayStation, Xbox and keyboard caps to the wishlist and target camera. Extra mod actions default to F6/F7 and can be rebound. Prompts follow the last input device; Steam Input may expose an Xbox-style device. Written tutorial text and artwork outside the recognized sheets are not replaced.

## Controls and combinations

| Mod action | Switch | Xbox | PlayStation | Keyboard default |
|---|---|---|---|---|
| Remove smithy pin / face selected target | ZL | LT | L2 | F6 |
| Pin smithy recipe / cycle target | ZR | RT | R2 | F7 |

Pin controls apply in the smithy; target controls apply in supported quest scenes.
Keyboard bindings are configurable in Controls. Extra triggers do not press PSP
L/R; the physical shoulder bumpers retain their native L/R functions.

- Target Camera is included in **Modern Right-Stick Camera**.
- Continuous gathering is included in **Gathering Nodes**.
- **Modern Camera** integrates with **Monster HP**, but also displays targets alone.
- **Controller Prompts** improves the displayed bindings for both Modern Camera and
  Equipment Material Pin; their actions also work without it.
- **Gathering Map Markers** and **Gathering Nodes** can be used together or separately.

## Package integrity and updates

[releases.json](releases.json) records each latest version, asset size and SHA-256.
[SHA256SUMS.txt](SHA256SUMS.txt) can be used to verify downloaded ZIPs.
Published assets preserve the locally released ZIPs byte-for-byte.

When publishing an update, replace that mod's older published version and update
its guide, download link and checksum. Older versions are not kept in this
repository's release assets. Detailed implementation notes and test limitations
are in the individual guides.
